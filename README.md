# KlempCinema

Kodi doplněk (plugin), který propojuje Kodi s **vlastním Webshare účtem** uživatele a zobrazuje metadata z TMDB.

**Verze: 0.0.185 (poslední)**

## Oznámení

Vývoj, podpora i další veřejné šíření tohoto doplňku končí. Další aktualizace nevycházejí.

Instalace, kterou už máš, může dál fungovat. Doplněk je nástroj k práci s tvým vlastním Webshare účtem — používej jen soubory, ke kterým máš oprávněný přístup.

## Požadavky

- Kodi 19+
- vlastní účet [Webshare](https://webshare.cz)
- TMDB API klíč ([zdarma](https://www.themoviedb.org/settings/api)) pro metadata

## Instalace

### Z repozitáře (aktualizace na 0.0.185)

1. **Nastavení → Průzkumník souborů → Přidat zdroj** →  
   `https://bicalordman.github.io/klempcinema/repo/`
2. **Doplňky → Nainstalovat ze ZIP** → zdroj výše → `repository.klempcinema-1.0.0.zip`
3. **Doplňky → Nainstalovat z repozitáře → KlempCinema Repository → KlempCinema**

### Ze ZIPu

Stáhni `plugin.video.klempcinema-0.0.185.zip` z [jediného release](https://github.com/bicalordman/klempcinema/releases/tag/v0.0.185) a nainstaluj přes **Doplňky → Nainstalovat ze ZIP**.

## Nastavení

V nastavení doplňku vyplň přihlášení k Webshare a TMDB API klíč.
